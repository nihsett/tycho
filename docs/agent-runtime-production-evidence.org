* IAM

The managed Runtime Agent Identity has these explicit project roles only:

- =roles/datastore.user=
- =roles/bigquery.dataViewer=
- =roles/bigquery.jobUser=
- =roles/telemetry.tracesWriter=

The dispatcher service account has:

- =roles/aiplatform.viewer= for Runtime query invocation;
- =roles/logging.logWriter=;
- =roles/run.invoker= on the dispatcher service itself.

The Google-managed Pub/Sub service agent has
=roles/iam.serviceAccountTokenCreator= on this dispatcher service account only.
This lets Pub/Sub mint the OIDC token whose identity and audience Cloud Run
validates after cutover.

The Runtime identity has no GCS or Pub/Sub roles. The dispatcher never writes
claims and sends only a validated =delta_id=.

Agent Identity uses certificate-bound credentials. The Runtime deployment sets
=GOOGLE_API_USE_CLIENT_CERTIFICATE=true= and =GOOGLE_API_USE_MTLS_ENDPOINT=always=.
Tycho explicitly constructs Firestore's mTLS gRPC transport because the pinned
high-level client otherwise targets the non-mTLS endpoint.
