  only in =tycho.delta_audit_log_20260826=.
- Comparison identity:
  =(obs_before, obs_after, generated_by, prompt_version)=.
- Grounding: a quote must occur within one actual source string field; JSON
  keys and adjacent fields cannot be concatenated into evidence.
- Mixed-product sources: sibling-product entries are excluded unless quoted
  content explicitly connects the change to the configured entity or one of
  its unmistakable components.
- Generation leases: transactional Firestore/SQLite ownership with durable
  failed/expired retry and shadow-to-semantic promotion.
- Noise is durable only in semantic mode; it is never published to Pub/Sub.
- Prompt, response, quotes, and source content are absent from generation-run
  metadata and ordinary logs.
