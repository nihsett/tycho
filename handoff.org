* Schemas and lifecycle
Strict Pydantic v2 models live in =schemas/=. All fixture and lifecycle tests pass.

Important final claim semantics:
- Fact: entity-primary evidence, confirmed.
- Normal inference: >=2 distinct sources, likely or speculative.
- Operational: =sources/<source>=.
- =inference_kind= is required on inferences:
  - =present_state=
  - =intent_or_future=
- Tool layer clamps =intent_or_future= confidence to speculative.
- =disputes= optionally links a speculative inference to an established claim.
- A one-source inference is valid if and only if =disputes= is set.
- Dispute evidence is exactly the current conflicting signal; counter-evidence is
  NOT dishonestly listed as support.
- A dispute inherits target scope/severity and leaves the target active.
- speculative+critical claim creation emits an alert.
- Primary-source evidence supersedes/resolves a dispute; the target's badge clears
  because no active inbound =disputes= link remains.
- Unsafe model demotion attempts still hit the original code-level demotion guard.

Lifecycle enforcement is in =pipeline/claims.py= and
=pipeline/gemini_analyst.py=, not left to prompts.

preserved on success and on failure. An ambiguous rename failure fails closed.
